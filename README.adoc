= CPPaste
Non-intrusive, sharable program framework for C++23 and beyond.
:toc:

== Features

=== Modules - Static and Dynamic Polymorphism

[cols="1,1,1"]
|===
||*Static* |*Dynamic*
|*Single Behavior*
|C++20 Concepts
|std::function or std::function_ref

|*Bundled Behavior*
|C++20 Concepts
|Abstract Base Class
|===

Allows shared downstream behavior for any case of polymorphism

There is a Directed Acyclic Graph representing all modules, both dynamic and static.
Static modules are allowed to depend on dynamic modules. However, the dynamic modules state will be unresolved.
Only when built will dynamic modules be resolvable.
